What are Advanced Stand-Level Constraints?

Advanced stand-level constraints let you define conditions that stands must meet to be eligible for treatment using available data layers.

For continuous variables, you can set thresholds (e.g., Probability of High Severity Fire > 0) to focus on higher-value stands.

For categorical variables, you must use the raster values that represent each class. For example, if Owl Habitat is coded as 1 = habitat and 0 = non-habitat, you would set Owl Habitat = 0 to avoid treating habitat areas.
